# Lab 7 - Using Wireshark to Analyze Network Traffic

CS2033 - Data Communication & Networking  
Department of Computer Science and Engineering, University of Moratuwa

## Overview

- Local host network configuration inspection (ipconfig /all)
- Live packet capture workflow and capture filter configuration
- Default gateway and LMS ICMP ping analysis
- Wireshark display filter syntax and protocol dissection (arp, icmp, dns, http)
- Protocol header field analysis and in-lab assessment evidence
